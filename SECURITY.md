# Sicherheitslücken melden

Kopfwetter speichert Gesundheitsdaten. Bitte melde Sicherheitsprobleme **nicht** als öffentliches Issue.

- **Wie:** Lege im GitLab-Projekt ein **vertrauliches Issue** an (Häkchen „This issue is confidential“) oder schreibe an die E-Mail-Adresse aus dem [Impressum](https://kopfwetter.app/impressum).
- **Was hilft:** betroffene Version oder Commit, Schritte zum Nachvollziehen, mögliche Auswirkung und gern ein Vorschlag zur Behebung
- **Antwort:** innerhalb von 7 Tagen. Eine Behebung wird so schnell wie möglich angestrebt, bei kritischen Lücken innerhalb von 30 Tagen.
- **Veröffentlichung:** gemeinsam abgestimmt, nachdem ein Fix bereitsteht. Wer möchte, wird in den Release-Notes genannt.

Bitte teste nur gegen eine eigene Installation, nicht gegen kopfwetter.app oder fremde Konten.

Das Verfahren und seine bekannten Grenzen beschreibt [docs/CRYPTO.md](docs/CRYPTO.md).

## Unterstützte Versionen

Sicherheitsupdates gibt es nur für den aktuellen Stand des Hauptzweigs.
